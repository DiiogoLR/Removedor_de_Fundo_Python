# Removedor de Fundo com Python 🖼️❌

[![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)](https://www.python.org/)

Este é um pequeno projeto em Python que **remove o fundo de uma imagem automaticamente** usando a biblioteca `rembg`.

## 📦 Bibliotecas utilizadas

- `rembg` – para remoção de fundo  
- `Pillow` – para abrir e salvar imagens

## ✅ Requisitos

Instale as dependências necessárias com:

```bash
pip install -r requirements.txt
```

## 💻 Como usar

1. Coloque a imagem original com o nome `imgfundo.jpg` na pasta do projeto.
2. Execute o script com o comando:

```bash
python app.py
```

3. O resultado será salvo na mesma pasta com o nome `imgsemfundo.png`.
